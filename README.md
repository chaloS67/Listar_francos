# Calculadora de Francos AXION

Aplicación de escritorio desarrollada en Python utilizando CustomTkinter.

Permite calcular automáticamente los próximos francos laborales a partir de:
- Fecha del último franco
- Cantidad de francos (1 o 2)

## Tecnologías utilizadas

- Python
- CustomTkinter
- datetime
- locale

## Funcionalidades

- Interfaz gráfica moderna
- Cálculo automático de francos
- Visualización de fechas y días
- Soporte para idioma español

## Cómo ejecutar el proyecto

1. Clonar repositorio

```bash
git clone https://github.com/chaloS67/gonzalo-dev-portfolio.git
```

2. Instalar dependencias

```bash
pip install customtkinter
```

3. Ejecutar aplicación

```bash
python3 python3 main.py
```
